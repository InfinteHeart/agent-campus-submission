# AI 辅助与人工交接

## 已发生的辅助

本项目在 Codex 协作中完成需求拆解、Python 代码、合成资料、工具接口、DeepSeek HTTP 适配、测试、真实模型运行和文档。业务 Agent 的 live 决策由 DeepSeek Flash 生成；Codex 负责项目实现与验证，两者不能混为一谈。

未创建多 Agent 实现，也未将离线 Mock 动作伪装成真实模型动作。

## 用户已提供的内容

用户提供考核规则、具体题目、验收边界，并指定 deepseek-flash 作为基座模型；用户在本地配置 API 密钥，密钥未纳入代码、Trace 或提交材料。

当前没有证据表明用户已经手工修改代码，因此不虚构“个人修改”。提交者应在实际阅读、修改后补充自己的记录。

## 实际修改与验证

AI 在首轮真实冲突测试中发现：模型建议 17:00，未满足项目定义的等距离优先向后偏好。修改时段工具，增加排序后的候选列表，并调整系统提示；保留失败原始记录，再运行真实模型验收。

另加入草稿版本与确认约束、保存前复查、事务写入后失败注入、并发占位测试、重复请求指纹检查、模型错误不自动降级 Mock 等验证，见 tests 和评估文档。

## 提交者应完成的个人验证

建议实际执行 README 命令，阅读两条 live Trace，修改占用时段后重复同一请求，解释 requested_at / suggested_at / scheduled_at 的差别，并说明为何未确认提案不占正式时段。将自己的修改 diff、运行输出和所花时间如实补入本文件；未做的工作不应写成已完成。
